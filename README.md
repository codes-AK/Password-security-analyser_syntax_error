
========================================
       PASSWORD SECURITY ANALYSER
========================================

PROJECT DESCRIPTION
-------------------
Password Security Analyser is a simple project
developed to check the strength of a password.

It analyses a password based on its length,
uppercase letters, lowercase letters, numbers
and special characters.

The project is designed for beginners and uses
basic programming concepts.


PROJECT FILES
-------------

1. index.html
   Contains the structure of the website.

2. style.css
   Controls the design, colours and layout.

3. script.js
   Performs password analysis and calculates
   the security score.

4. password_analyser.c
   Contains the C language version of the
   password analyser.

5. README.txt
   Contains project information and instructions.


FEATURES
--------

1. Checks password length.
2. Detects uppercase letters.
3. Detects lowercase letters.
4. Detects numbers.
5. Detects special characters.
6. Calculates a security score.
7. Displays password strength.
8. Provides suggestions to improve passwords.
9. Includes a show/hide password option.
10. Allows users to clear the password.


SCORING SYSTEM
--------------

Each condition gives one point.

1. At least 8 characters       - 1 point
2. Uppercase letter            - 1 point
3. Lowercase letter            - 1 point
4. Number                      - 1 point
5. Special character           - 1 point

TOTAL SCORE: 5


PASSWORD STRENGTH
-----------------

0 - 2 : WEAK
3 - 4 : MEDIUM
5     : STRONG


HOW TO RUN THE WEBSITE
----------------------

1. Extract the project folder.
2. Open the project folder.
3. Double-click index.html.
4. The website opens in your browser.
5. Enter a sample password.
6. View the security score and analysis.


HOW TO RUN THE C PROGRAM
-----------------------

1. Open password_analyser.c in Code::Blocks
   or another C programming IDE.
2. Compile the program.
3. Run the program.
4. Enter a sample password.
5. View the analysis result.


PROGRAMMING LANGUAGES
---------------------

HTML       - Website structure
CSS        - Website styling
JavaScript - Website functionality
C          - Basic password analysis program


CONCLUSION
----------

The Password Security Analyser is a beginner-
friendly project that demonstrates how passwords
can be evaluated using basic conditions.

It helps users understand the importance of
creating stronger passwords.


IMPORTANT NOTE
--------------

This project is developed for educational purposes.
It uses a basic scoring method and does not guarantee
complete password security.

Do not enter real or reused passwords.
